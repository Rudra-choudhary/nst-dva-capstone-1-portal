Capstone Introduction

This capstone project is designed as an industry style data analytics simulation where student teams solve real world sectoral problems using structured data. The objective is to demonstrate end-to-end analytical capability, not just tool usage or visualization skills. Teams are expected to think like professional analysts and convert raw data into decision oriented insights.

Each team will select a sector and a problem statement, then execute a complete analytics workflow that includes data understanding, cleaning, standardization, KPI design, exploratory analysis (trends/outliers), statistical analysis (correlation, distribution, variability), dashboard creation, and recommendation building. The final output should clearly demonstrate structured thinking, analytical depth, and decision relevance.

This capstone is part of the Data Visualization course. Therefore, Google Sheets is the mandatory working platform for cleaning, analysis, and dashboard creation.

Dashboarding Extension: While the primary analysis must be performed in Google Sheets, teams are permitted (and encouraged) to use Looker Studio for the final dashboard layer to demonstrate advanced visualization capabilities. However, the underlying data preparation and cleaning logic must remain visible in the Master Google Sheet.

Optional Support: Students may use Python for supporting analysis (e.g., complex statistical grouping), but it is not mandatory. SQL is not required. Evaluation will focus on analytical thinking and Google Sheets mastery, not on tool complexity.

Mandatory Tool

Google Sheets for data cleaning, analysis, and dashboarding.

Evaluation Focus

Insight quality, analytical structure, and recommendation strength.

Optional Support

Python/SQL can support work but are not mandatory for grading.

Capstone Workflow

  1. DefineSelect sector, define problem statement.
  2. PrepareClean and standardize data in Google Sheets.
  3. AnalyzeTrends, outliers, distribution and correlation analysis.
  4. VisualizeBuild dashboards and storytelling views.
  5. RecommendDeliver actionable business recommendations.
